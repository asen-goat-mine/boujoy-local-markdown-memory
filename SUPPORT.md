# Support

## Start here

1. Read the [three-minute setup](README_EN.md#three-minute-start) or [中文快速开始](README.md#三分钟开始).
2. Check [Troubleshooting](docs/troubleshooting.md).
3. Run the read-only diagnostics:

~~~bash
python3 tools/vault_doctor.py
python3 tools/sync_index_status.py --check
~~~

## Ask for help

Use GitHub Discussions when available for setup questions and workflow ideas. Use a bug report for reproducible defects and include:

- operating system and Python version;
- the exact command used;
- the shortest error output that reproduces the problem;
- whether full mode or browser compatibility mode was used.

Never attach a private Vault, credentials, personal paths, customer data, or confidential screenshots.

## Security issues

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.
