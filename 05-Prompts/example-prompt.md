# Example prompt: checkpoint a project

## One-sentence conclusion

A reusable prompt states when it applies, what it receives, what it must produce, and what it must not do.

## Use cases

## Prompt

> Checkpoint the current project. Record only completed work, current decisions, the next action, blockers, and real verification results. Update the project card and Active Context. Do not save the raw conversation or describe an unexecuted plan as complete.
