## One-sentence conclusion

Use one project card to preserve the goal, current decisions, verified progress, blockers, and next action.

## Use cases

Use this structure when work spans multiple sessions or needs a clean continuation point.

## Key decisions

- Record actual state, not optimistic plans.
- Replace obsolete decisions instead of keeping conflicting instructions active.
- End each work session with one concrete next action.

## Reusable method

1. Define the outcome.
2. Keep only the currently valid decisions.
3. Record what was actually verified.
4. State the next action and any blocker.
