# Privacy

This repository contains program code, generic rules, starter indexes, synthetic examples, and one reviewed product-UI demo animation. It does not contain author knowledge, personal projects, private prompts, preferences, logs, private media, or Skills.

The preview service binds to `127.0.0.1`, has no telemetry, and makes no external network request. It reads the current Vault and never writes Markdown.

Local-first does not mean that every tool around the Vault is offline. Codex, WorkBuddy, your browser, and your Git hosting provider are separate products governed by their own data policies.

Do not publish a personal working Vault to a public repository. Keep private knowledge in a private repository or separate the public source tree from the personal Vault.
