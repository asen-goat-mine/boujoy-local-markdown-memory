# Dedup Rules

## 写入前检查顺序

1. `Memory-Index.md`
2. `Hot-Index.md`
3. 目标目录中的相关文件名
4. 必要时读取最相关的 1-3 个已有文件

## 判断重复

以下情况优先视为同一主题：

- 结论相同，只是例子不同
- 解决的是同一问题
- 新内容只是已有方法的补充步骤
- 标题不同，但触发词和适用场景高度重合

## 处理方式

- 补充信息：更新原文件的正文或“更新记录”
- 更准确的新判断：保留新判断，并标记旧判断已更新
- 旧内容不再适用：标记已废弃，说明替代结论
- 真正独立的新主题：新建文件并加入索引

不要为了记录一次对话而制造第二份相同知识卡。
